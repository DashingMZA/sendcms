Contact us — live demo

This is the real Contact us form from SendCMS. Try it two ways: the JavaScript SDK (one script tag, the form just works) or the REST API (a plain fetch call). Submissions land in the dashboard inbox.

Note: a submission is only accepted when this page's domain is a verified domain linked to the form. If you see “This form does not accept submissions from this site”, link this domain to the form in the dashboard (Domains → verify → Forms → link it).

JavaScript SDK

Add the script tag and a form[data-cms-form] — the SDK enhances the form, handles the submit, and shows the status itself.

Embed code

<script src="https://api.sendcms.bond/forms/v1.js"
  data-user-id="shSSZJGS9txSlU7DmPksq1qXuIxpJDcI"
  data-form-id="cmwlcr5xs0000gouynm83kjpm"></script>

<form data-cms-form>
  <input name="name" required />
  <input name="email" type="email" required />
  <input name="company" />
  <select name="reason" required>
    <option>Support</option>
    <option>Sales</option>
    <option>Partnership</option>
    <option>Other</option>
  </select>
  <textarea name="message" required></textarea>
  <button type="submit">Send</button>
</form>

REST API

A plain fetch POST to /api/public/v1/submit — no SDK, no script tag. The response is shown below the button.

Request

const res = await fetch(
  "https://api.sendcms.bond/api/public/v1/submit",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      userId: "shSSZJGS9txSlU7DmPksq1qXuIxpJDcI",
      formId: "cmwlcr5xs0000gouynm83kjpm",
      fields: {
        name, email, company, reason, message,
      },
      idempotencyKey: crypto.randomUUID(),
      pageUrl: window.location.href,
    }),
  }
);
// 201 → { ok: true, id, message, redirectUrl }
